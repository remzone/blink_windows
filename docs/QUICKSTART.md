# Blink для Windows: инструкция для новичков

[Скачать приложение и посмотреть скриншоты](../README.md#скачать)

## Что нужно до начала

Компьютер с Windows 10 или 11, доступ в интернет и подписка вашего VPN-сервиса. Подписка обычно выглядит как длинная HTTPS-ссылка; также сервис может выдать файл конфигурации. Blink подключает эти профили, но не создаёт для вас подписку.

## 1. Выберите сборку

В параметрах Windows найдите **«Тип системы»**:

- **64-разрядная операционная система** — скачайте **x64**.
- **32-разрядная операционная система** — скачайте **x86**. Эта сборка предназначена для Windows 10 x86.

Готовые архивы находятся в [таблице загрузок](../README.md#скачать). Архив **Code → Download ZIP** на GitHub содержит исходный код и для обычной установки не нужен.

## 2. Распакуйте и запустите

Нажмите правой кнопкой мыши по ZIP → **Извлечь всё**. Откройте распакованную папку и запустите `Blink.exe`. Не переносите один EXE отдельно: рядом нужен `wintun.dll`, который уже есть в архиве. Это компонент сетевого адаптера.

Подтвердите запрос Windows на внесение изменений. Он нужен для настройки сети. Если Blink сообщает, что отсутствует WebView2, установите [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) с сайта Microsoft и повторите запуск. Устанавливать инструменты разработчика для работы Blink не нужно.

## 3. Добавьте свою подписку

1. Скопируйте ссылку, которую выдал ваш VPN-сервис.
2. В Blink откройте **Профили → Добавить**.
3. Вставьте ссылку в окно добавления и подтвердите импорт. Если у вас файл конфигурации, выберите импорт из файла.
4. Дождитесь появления списка серверов.

Ссылка на подписку и адрес страницы личного кабинета могут различаться. Если импорт не удаётся, уточните правильную ссылку у сервиса. Логин и пароль от панели управления вводить в Blink не нужно. Не публикуйте подписку в общих чатах.

## 4. Выберите сервер и подключитесь

В списке найдите сервер по названию или стране и нажмите на него. Перейдите в **Подключение**, нажмите **Подключиться** и дождитесь **«Соединение активно»**. Если внутри приложения появится ручная проверка, выполните её и дождитесь продолжения.

Для проверки откройте нужный сайт. В разделе **Диагностика** также доступны проверки внешнего IP, Google и YouTube. Чтобы завершить соединение, нажмите **Отключиться**.

## Подписки и выбор сервера

**Профиль** — настройки конкретного сервера. **Подписка** — источник, из которого Blink получает один или несколько профилей.

В Blink есть два типа подключения:

| Тип | Когда выбирать |
| --- | --- |
| **Обычный VPN** | У вас обычные VPN-профили от сервиса. |
| **TURN** | Ваш сервис выдал профили с транспортом TURN. |

Если сервис выдал две ссылки — обычную и TURN — добавьте каждую через **Профили → Добавить**. Они сохраняются независимо. Пустая вкладка означает, что профили этого типа ещё не импортированы.

Для смены сервера сначала отключитесь, затем выберите тип и сервер. Кнопка **Все серверы** открывает полный список. Поиск понимает названия стран на русском и английском, имя сервера и протокол. Если серверов не видно, очистите поиск и выберите **Все**.

В **Профилях** у подписок отдельные карточки: обновляйте нужную кнопкой обновления. Это нужно, когда сервис добавил серверы или изменил настройки. Сначала отключитесь. Удаление карточки подписки удаляет только её профили.

## Настройки при первом запуске

Оставьте параметры по умолчанию. Настройки TURN и маршрутизации меняйте, если ваш сервис дал конкретные значения или вы понимаете, какой результат нужен. Для обычного первого подключения достаточно добавить подписку и выбрать сервер.

## Обновление Blink

Отключитесь, полностью закройте старое приложение, скачайте новый архив и распакуйте его в новую папку. Открывайте EXE из новой папки. Подписки и настройки сохраняются для текущего пользователя Windows; переимпорт не нужен. При переходе на другой компьютер или другую учётную запись Windows добавьте подписки заново.

## Как сообщить об ошибке

1. Запомните выбранный тип подключения и сохраните текст ошибки.
2. Откройте **Диагностика → Открыть папку журнала**.
3. Передайте в поддержку `blink.log` и `blink.log.1`, если он есть. Папку можно открыть вручную: вставьте `%APPDATA%\Blink\logs` в адресную строку Проводника.

В журнал не записываются ключи и ссылки подписок; автоматической отправки нет. Если после аварийного завершения нарушилась работа сети, используйте **Настройки → Восстановить сеть** и сохраните журнал при повторной ошибке.
