# Blink для Windows — как начать пользоваться

Blink теперь работает на Windows. Подключение в версии **0.3.0-preview.4** подтверждено пользователем после исправления сетевой настройки. Доступны сборки для 64-битной и 32-битной Windows.

В приложении можно хранить обычную VPN-подписку и TURN-подписку одновременно, быстро переключаться между ними и искать сервер по названию или стране. Выбранные серверы сохраняются после перезапуска.

**Как подключиться:**

1. [Откройте страницу загрузки](https://github.com/remzone/blink_windows#скачать). Для Windows 10/11 на 64 бита выберите **x64**, для Windows 10 на 32 бита — **x86**. Разрядность указана в параметрах Windows в поле «Тип системы».
2. Распакуйте скачанный ZIP целиком и запустите **Blink.exe**. Файл **wintun.dll** должен остаться рядом с EXE. Подтвердите запрос Windows на внесение изменений.
3. Откройте **Профили → Добавить** и вставьте ссылку подписки от своего VPN-сервиса. Если у вас две подписки — обычная и TURN — добавьте обе по очереди.
4. Выберите сервер, перейдите в **Подключение** и нажмите **Подключиться**. Дождитесь статуса **«Соединение активно»**.

Для смены сервера или типа подключения сначала нажмите **Отключиться**. Большой список можно открыть кнопкой **Все серверы** и отфильтровать поиском.

Blink не выдаёт подписку: нужна ваша ссылка или файл конфигурации от VPN-сервиса. При первом запуске оставьте настройки по умолчанию. Если приложение сообщает об отсутствии WebView2, ссылка на установку есть в инструкции.

**Если возникла ошибка:** откройте **Диагностика → Открыть папку журнала** и передайте в поддержку `blink.log`, а также `blink.log.1`, если он есть. Саму ссылку подписки в общий чат не отправляйте.
