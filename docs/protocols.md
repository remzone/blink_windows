# Протоколы и форматы 0.1.0

| Формат / backend | Импорт | Подключение Windows |
| --- | --- | --- |
| VLESS, VMess, Trojan, Shadowsocks URI | Общий парсер | Xray, только IPv4 ОС-интерфейс |
| Hysteria2 URI | Общий парсер | Xray |
| Xray JSON / JSON-массив | Сохраняет поддерживаемые routing/DNS/streamSettings | Xray; direct-правила остаются явными исключениями |
| XDRIVE | Только JSON, как в iOS/Android | Закреплённое ядро Xray с xdrive transport |
| Clash YAML | Только поддерживаемые узлы | Группы, DNS и правила Clash не применяются; уведомление при импорте |
| TUIC v5 / Hysteria v1 | URI | sing-quic |
| WG / AWG `.conf`, поддерживаемые WG/AWG URI | Общий парсер | Пакетный WG/AWG backend; IPv6-конфигурации отклоняются |
| Обычная подписка plain/base64 | До 1 МиБ / 1024 строк | Узлы валидируются отдельно, показано число отклонённых |
| Vokop v1 | До 16 TURN-профилей | VLESS → KCP → smux → DTLS → VK TURN, Auto UDP/TCP |
| Vokop v2 WG | `.conf` + транспорт панели | WG через DTLS, SRTP или WRAP, без IPv6 ОС-конфигурации |
| Vokop v3 / routing / turn.options | Отклоняется | Нет UI/переноса этих политик в 0.1.0 |
| OpenVPN / AnyConnect / Forti | Нет | Нет |

Список обозначает реализованные пути кода, а не результат проверки каждого протокола на Windows или доступность конкретного провайдера. Реальная Windows-проверка ещё не выполнена.

VK поддерживает только официальные HTTPS-ссылки `https://[www.]vk.com/call/join/ID` и `https://[www.]vk.ru/call/join/ID`. Исходная ссылка сохраняется; core сравнивает проверенные ID с учётом регистра. Подменные домены, query, fragment и кодированный путь отклоняются.

Современная CAPTCHA требует официального SDK и пока не подключена. Legacy-код отправляется только в текущий challenge ядра, привязанный к ID и сроку. Нет обхода проверки, доступа к cookies приложения VK или автоматического решения. Отдельный прямой диагностический режим мобильного клиента в UI Windows не добавлен.

Расширенная конфигурация Xray может определять собственные DNS/direct outbounds и тем самым менять маршрутизацию. Правила Windows не превращают такую конфигурацию в обязательный полный туннель. Для WG частичные AllowedIPs намеренно оставляют остальной трафик в физической сети.
