# Blink для Windows 0.3.0-preview.4

18 ноября 2026 пользователь подтвердил работу приложения и подключения на Windows после перехода на временную защиту IPv6 через WFP. Обозначение preview пока сохранено; отдельная проверка 32-битной ОС и всех протоколов этим сообщением не подтверждается.

[Скачать x64](https://github.com/remzone/blink_windows/raw/refs/heads/main/testing/0.3.0-preview.4/Blink-Windows-0.3.0-preview.4-x64.zip) · [Скачать x86, 32 бит](https://github.com/remzone/blink_windows/raw/refs/heads/main/testing/0.3.0-preview.4/Blink-Windows-0.3.0-preview.4-x86.zip) · [SHA256SUMS](SHA256SUMS)

1. Выберите x64 для 64-разрядной Windows 10/11 или x86 для 32-разрядной Windows 10.
2. Распакуйте архив целиком. Оставьте `Blink.exe` и `wintun.dll` рядом, запустите EXE и подтвердите запрос Windows на внесение изменений.
3. Откройте **Профили → Добавить**, импортируйте подписку от своего VPN-сервиса или файл конфигурации. Обычную подписку и TURN-подписку можно добавить по очереди: они хранятся независимо.
4. Выберите сервер и нажмите **Подключиться**. Для смены сервера или режима сначала отключитесь.

При обновлении полностью закройте старый Blink и распакуйте новый архив в другую папку. Сохранённые подписки текущего пользователя Windows останутся на месте. При отсутствии WebView2 Runtime ссылка на его установку есть в инструкции.

Если возникла ошибка, откройте **Диагностика → Открыть папку журнала** и передайте в поддержку `blink.log` и `blink.log.1`, если он есть. Журналы находятся в `%APPDATA%\Blink\logs`, ключи и ссылки подписок в них не записываются.

Архивы обновлены только в части документации: EXE и DLL совпадают с версией, для которой получено подтверждение пользователя. Поэтому версия приложения не изменена; SHA-256 архивов пересчитан.
