# Диагностический preview 0.3.0-preview.1

Это **не подтверждённый рабочий релиз**. Архивы 0.2.x отозваны после сообщения о зависании обоих типов подключения. Preview исправляет хранение независимых подписок, отмену/ограничение ожидания и добавляет отчёт для выяснения причины на Windows.

[Скачать x64](https://github.com/remzone/blink_windows/raw/refs/heads/main/testing/0.3.0-preview.1/Blink-Windows-0.3.0-preview.1-x64.zip) · [Скачать x86, 32 бит](https://github.com/remzone/blink_windows/raw/refs/heads/main/testing/0.3.0-preview.1/Blink-Windows-0.3.0-preview.1-x86.zip) · [SHA256SUMS](SHA256SUMS)

1. Распакуйте архив целиком; EXE и Wintun DLL должны лежать рядом. Нужен WebView2 Runtime.
2. Добавьте обычную VPN-подписку и TURN-подписку: в этой версии они сохраняются независимо. Существующая сохранившаяся подписка мигрирует; ранее удалённую старым импортом нужно добавить повторно.
3. Выберите профиль и подключитесь. На главной появится конкретный этап и прошедшее время.
4. При ошибке или после отмены откройте **Диагностика → Скопировать отчёт**. Он содержит только этапы, коды и числа, без ключей, ссылок подписок, адресов серверов и пакетов. Автоматической отправки нет.

Go race tests и browser tests независимых источников/этапов/отчёта прошли, EXE x64/x86 скомпилированы. Реальный Windows-драйвер и VPN-подключение в этой среде не запускались. EXE не подписан Authenticode.
